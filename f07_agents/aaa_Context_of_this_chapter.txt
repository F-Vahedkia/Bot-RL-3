3. f07_agents/symbol_agent.py
============================================================

نقش:
اجرای یک Symbol-Agent مستقل برای یک symbol.

مالک:
تحلیل و تصمیم symbol-level.

ورودی:
    AgentObservation
    SymbolContext
    decision_id
    Policy

خروجی:
    SymbolAgentOutput

Symbol-Agent اجازه ندارد:
    capital allocation کل Portfolio را تعیین کند.
    correlation بین نمادها را مدیریت کند.
    Portfolio risk را تعیین کند.
    execution انجام دهد.
    broker را صدا بزند.

هر instance فقط یک symbol را نمایندگی می‌کند.

ساختار اصلی:

SymbolAgentConfig
    symbol
    mode
    model
    min_confidence
    enabled

SymbolPolicy
    interface مربوط به Policy.
    نقطه اتصال آینده به:
        RL Policy
        Neural Network
        Transformer
        Ensemble
        ...

SymbolAgent
    decide()
    update_reward()
    reset()

decide():
    observation را برای همان symbol بررسی می‌کند.
    Policy را صدا می‌زند.
    خروجی را validate می‌کند.
    confidence guardrail را اعمال می‌کند.
    SymbolAgentOutput تولید می‌کند.
    runtime state را update می‌کند.

نکته:
RL algorithm نباید در خود SymbolAgent hard-code شود.
Policy باید قابل تعویض باشد.

6. f07_agents/action_builder.py
============================================================

نقش:
تبدیل تصمیم معنایی Meta-Agent به
PortfolioAction قابل فهم برای f06_env.

مرز:

PortfolioDecision
        ↓
PortfolioActionBuilder
        ↓
f06_env.PortfolioAction

این فایل execution انجام نمی‌دهد.

مشکل مهمی که جدا شده:
PortfolioDecision ممکن است exposure بدهد،
اما f06_env به target_lots نیاز دارد.

بنابراین:

PositionSizer
    یک interface قابل تزریق است.

PositionSizer:
    exposure
        ↓
    target lots

این باعث می‌شود بعداً sizing بر اساس مواردی مانند:
    equity
    volatility
    contract specification
    risk budget
    margin
    leverage
    stop distance
    instrument rules

قابل تعویض باشد.

PortfolioActionBuilder:

    اگر Decision رد شده باشد:
        PortfolioAction خالی

    اگر symbol نامعتبر باشد:
        reject

    اگر signal = 0:
        target_lots = 0

    اگر signal != 0:
        PositionSizer حجم را تعیین می‌کند.

خروجی:
    f06_env.PortfolioAction

اصل مهم:
Action Builder فقط translation است،
نه Risk Engine،
نه Execution Engine.

============================================================
IMPORTANT DESIGN PRINCIPLES
============================================================

1. Symbol-Agent ها مستقل از یکدیگرند.

2. Meta-Agent تنها لایه‌ای است که Portfolio-wide information
   را برای تصمیم‌گیری جمع می‌کند.

3. RL Policy باید قابل تعویض باشد؛
   Agent نباید به یک الگوریتم خاص RL قفل شود.

4. Position sizing قابل تعویض است.

5. Decision باید قابل Audit و Replay باشد.

6. timestamp در هر decision cycle باید سازگار باشد.

7. model identity و experiment lineage باید حفظ شوند.

8. train / optimize / backtest / replay / eval /
   shadow / paper / live باید همان معماری تصمیم‌گیری را
   با policy/runtime متفاوت استفاده کنند.

9. هیچ Agent نباید مستقیماً Broker را صدا بزند.

10. تصمیم Portfolio با اجرای معامله دو لایه مستقل هستند.
